# 🤖 AXIS — Многофункциональный Бот с ИИ
Open-source бот для автоматизации сообществ, интеграции искусственного интеллекта и поддержания порядка в чатах. Проект создан с акцентом на простоту развертывания и гибкость в настройке.
## 🚀 Основные возможности
 * 🧠 **Искусственный интеллект**: Интеграция с ИИ-моделью для умных ответов на вопросы и интерактивного общения.
 * ⚙️ **Простая настройка**: Удобный встроенный скрипт первичной конфигурации installer-start.py.
 * 🔄 **Авто-обновления**: Поддержка быстрой синхронизации изменений с GitHub с помощью утилит автоматизации.
## 🛠️ Стек технологий и зависимости

* **Язык программирования:** Python 3.x
* **ИИ-сервер:** Ollama
* **47 строчка внутри указывается имя модели**
* **Библиотеки Python:**
  * `discord.py` — для работы с API Discord (включая `app_commands` и `ext.commands`)
  * `requests` — для выполнения HTTP-запросов к API
## 📦 Быстрый старт
### 1. Клонирование репозитория
```bash
git clone https://github.com/eiehei773u3-byte/AXIS.git
cd AXIS

```
### 2. Первичная настройка
Запустите скрипт первичной настройки для ввода токена бота и указания вашего ID администратора:
```bash
python installer-start.py

```
### 3. Запуск бота
После завершения настройки запустите основного бота:
```bash
cd bot
python core.py

```
